# CodeAlpha Calculator

A responsive calculator built using HTML, CSS and vanilla JavaScript for the CodeAlpha Frontend Development Internship.

## Features

- Addition, subtraction, multiplication and division
- Percentage operation
- Decimal values
- Clear and delete controls
- Real-time display
- Keyboard support
- Responsive design
- Hover and click animations
- Error handling for invalid calculations

## Run

Open `index.html` in any modern browser.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
