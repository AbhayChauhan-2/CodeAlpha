# CodeAlpha Image Gallery

A responsive image gallery built with HTML, CSS and vanilla JavaScript for the CodeAlpha Frontend Development Internship.

## Features

- Responsive gallery layout
- Nature, City and Travel categories
- Category filtering
- Full-screen lightbox
- Previous/Next navigation
- Keyboard navigation
- Hover effects
- Smooth transitions
- Image lazy loading
- Mobile-friendly layout

## Run

Open `index.html` in any modern browser.

The gallery currently uses remote images from Unsplash. An internet connection is required for those images to load.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
